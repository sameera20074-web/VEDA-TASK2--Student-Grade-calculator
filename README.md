# VEDA TASK 2 - Student Grade Calculator

## 📌 Objective
Practice conditional statements (if, elif, else) and apply them to student data.

## 🎯 Project Overview
This project calculates student grades based on marks using if-elif-else logic and handles invalid inputs.

## 📊 Grading Logic
- 90-100 : A - Excellent
- 80-89  : B - Very Good  
- 70-79  : C - Good
- 60-69  : D - Pass
- Below 60 : F - Fail
- <0 or >100 : Invalid Marks

## 💻 Features
- Function `calculate_grade()` used
- Handles invalid marks
- Tested with 6 students including edge case
- Clean formatted output
